# 3.0.5 发布说明

发布日期：2026-10-22。目标版本：`schema-dsl@3.0.5`，标签：`v3.0.5`。

## 修复

- 验证快路径保留与 `enum` 同时声明的 `type` 约束。
- 多个组合关键词同时出现时保守回退 AJV；内部 IR 明确标记不支持的合取。
- 正则匹配遵循 AJV 的 Unicode 语义，支持 `unicodeRegExp: false`，自定义 `code.regExp` 引擎交由 AJV。
- 更新受影响的运行与开发依赖；Vitest/coverage 同步至4.1.12，Vite7.3.7，移除跨主版本 YAML override。
- 网站 React Router / React Router DOM 从7.15.0更新至7.18.4，保持 Rspress 现有7.x兼容范围，不新增运行库依赖。
- 修复网站首页 hero 基础样式依赖，并保留桌面/移动端布局回归覆盖。

## 发布验证改进

- 根包与网站拥有独立 lockfile，分别执行 dependency audit。
- CI、Pages和npm发布在网站安装后执行网站 audit；发布工作流不再忽略根完整 audit 失败。
- `prepublishOnly` 复用 `test:all:with-audit`，覆盖根运行/开发依赖及网站依赖；阈值为 moderate 或以上。
- 新增隔离 npm-script 回归，检查网站 audit 正常通过，以及失败沿根转发、完整验证、预发布入口传播。
- 发布工作流在完整验证后生成一次 tarball，核对摘要后上传同一文件；发布成功记录独立回执，再核验 registry，避免验收重试造成重复发布。

## 兼容性

无公开 API 或 exports 变更。发布库运行基线保持 **Node.js >=18.0.0**；完整开发工具链使用 Node.js22.13.0、22.x和24.x，推荐24 LTS。网站工具链使用Node24；Router7.18.4要求Node>=20、React/ReactDOM>=18，与当前网站环境兼容。

CI使用同一构建tarball验证Node18.0.0、18、20、22.13.0、22和24的运行消费；Node24另检查Node18公开类型声明。旧Node运行兼容不等于其上游安全维护仍然有效。

网站为静态Pages；上游公告的SSR/RSC限定条件不能直接推断为本站可利用。依赖更新覆盖已公开修补范围，详见[Router安全公告](https://github.com/remix-run/react-router/security/advisories/GHSA-qwww-vcr4-c8h2)。

## 升级

无需运行时迁移。可通过 `npm install schema-dsl@3.0.5` 升级；完整验证、发布与来源证明由对应提交及 `v3.0.5` 的 GitHub Actions 记录提供。
